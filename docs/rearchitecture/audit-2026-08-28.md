## Discrepancies and resolutions

- `TileRenderer` and `TileRegistry` are defined in `core/src/tile.rs`; the daemon
  re-exports them. The current-state map now says so.
- Egui code has been removed. Remaining references are comments/stubs; the shell
  is Nannou plus custom modal/control code.
- The map omitted `Transform` and the legacy `ModuleImpl`/`ModuleHandle` forms;
  they and the actual routing/lifecycle tests are now explicit.
- Legacy tests do not prove prepared activation or last-good behavior. Those are
  new target contracts with new acceptance scenarios.
- `SttProcessor` emits `source = "speech_to_text"`, while replaceable overflow
  classification matches `"stt_partial"`. Draining a queue and retaining only
  the newest event is not proof that finals are retained.
- The earlier matrix omitted repository automation, toolchain/configuration,
  scripts, host diagnostics, environment examples, assets, tracked binaries,
  and several old-core-dependent crates. The matrix now assigns each a cutover
  disposition and forbids uncompilable parking crates.
- The microphone/ASR document described a later vertical slice as first. The
  first slice is now only the portable domain/protocol/client/application/runtime
  foundation and deterministic mock round trip.
- Native Rust remains authoritative for GPU computation and resource ownership.
  Browser WebGL2/WebGPU may accelerate presentation only.
